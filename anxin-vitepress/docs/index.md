# 安心医疗系统 API 文档

欢迎访问安心医疗系统的 API 文档网站！

本网站基于 **Vue3 + Vite + VitePress** 构建，涵盖了系统所有主要模块的接口说明，帮助开发者快速对接和理解后端服务。

## 如何使用本网站？

- 请点击**左侧 API 模块导航栏**，进入各功能模块的详细接口文档页面。
- 可使用**右上角的全局搜索**功能，快速查找接口、参数或说明。
- 每个模块文档均包含接口地址、请求方式、参数说明、示例和响应格式。
