# Anxin Medical System API Docs

Welcome to the API documentation site for Anxin Medical System!

This site is built with **Vue3 + Vite + VitePress** and covers all major modules of the system, helping developers quickly integrate and understand backend services.

## How to use this site?

- Click the **API Modules** in the left sidebar to view detailed documentation for each module.
- Use the **global search** in the top right to quickly find endpoints, parameters, or descriptions.
- Each module includes endpoint, method, parameters, examples, and response format.
